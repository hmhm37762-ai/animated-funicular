نشر «صلاتي نور» (نسخة الويب)

الأسهل: Netlify Drop
1) افتح الرابط: https://app.netlify.com/drop  (من الكمبيوتر أسهل)
2) فك ضغط الملف، ثم اسحب المجلد كاملًا (index.html وباقي الملفات) إلى الصفحة.
3) سيعطيك رابطًا بصيغة https. افتحه من هاتفك في Chrome.
4) من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية / تثبيت التطبيق».
5) أنشئ حسابًا مجانيًا في Netlify لتبقى الصفحة دائمة (بدونه تُحذف بعد وقت قصير).

بدائل: GitHub Pages أو Cloudflare Pages (ارفع نفس الملفات).

ملاحظات:
- لا بد من رابط https ليعمل الموقع والبوصلة والإشعارات.
- أول فتح لقسم القرآن يحمّل المصحف مرة واحدة (نحو ١ ميغابايت) ثم يعمل دون إنترنت.
